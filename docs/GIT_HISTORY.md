# Required Git History

The assignment requires at least 8 meaningful commits.

Use this sequence:

1. `Initial domain model without factories`
2. `Add product abstractions`
3. `Introduce Factory Method`
4. `Add product families`
5. `Introduce Abstract Factory`
6. `Add runtime factory selection`
7. `Add tests and compatibility rules`
8. `Add fourth product family`

Do not create fake empty commits. Each commit should correspond to an actual development step.

For the submitted repository, the final history should show the evolution from the direct-creation version to the factory-based design.
